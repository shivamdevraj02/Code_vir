# Node.js MVC Backend Project

A **Node.js backend project** built using the **MVC (Model-View-Controller) architecture**. This repository demonstrates core server-side development concepts such as routing, views, utility modules, middleware, request handling, and structured project organization.

The project is designed to strengthen backend development skills while following a clean, modular, and maintainable code structure.

## 🚀 Features

* MVC architecture
* Express.js server setup
* Route handling
* Middleware implementation
* Request and response handling
* View rendering
* Utility/helper modules
* Organized folder structure
* Modular and maintainable backend code
* Basic server-side development concepts

## 🛠️ Technologies Used

* **Node.js**
* **Express.js**
* **JavaScript**
* **EJS / Template Engine**
* **HTML & CSS**
* **NPM**

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

## ▶️ Run the Project

Start the development server:

```bash
npm start
```

Or, if using Nodemon:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
